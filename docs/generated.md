## PhiBase Service Integration

Integrates PhiBase service to convert whisper transcripts into structured documentation sections.

- Automatically generates documentation PRs from walkthrough videos.
- Uploads an MP4 file for processing.
- Opens a PR updating the documentation.

## Documentation Generation

Generates structured documentation sections from video walkthroughs.

- Summary and bullet points derived from the video.
- Vague walkthroughs may result in vague documentation.
